# Editorial portfolio

The owner's implementation brief supersedes the earlier shell-only proposal.
Identity: Nguyễn Văn Duy / Computer Science Student. Direction: ML Systems,
MLOps, ML Infrastructure, Platform Engineering and research-oriented systems.

Shared avatar/identity header, seven flat navigation links and separate VI / EN
utility; open main region; email/location footer opposite social links. No
persistent sidebar, dashboard enclosure, service marketing, command UI or audio.

Near-black neutral surfaces, off-white type, subtle borders and small radii.
Retain a muted warm accent from the site's existing warm token family and the
approved editorial plan, independent of reference branding. Headings stay neutral.
Local Atkinson font, Astro-rendered HTML, optimized owner photographs, minimal JS.
Static geometry must be less noticeable than the content.

Homepage: identity, short direction, current SITES work, two selected projects,
Portfolio/GitHub/Resume links. Listing rows lead to factual project details.
Blog is initially empty; Gallery and PDF CV remain available.

Browser output is the design artifact. Review desktop → tablet → mobile, then
content, keyboard use, reduced motion and generated production HTML. No Figma,
third-party assets, raw mirrors, temporary design routes or new runtime framework.
