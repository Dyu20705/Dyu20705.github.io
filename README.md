## ✨ What This Site Is

This repository powers [dyu20705.github.io](https://dyu20705.github.io), a personal portfolio shaped around:

- 🤖 MLOps, machine learning systems, and reproducible pipelines
- ☁️ Cloud, Linux, Docker, automation, and deployment foundations
- 🧪 Honest project storytelling: clear status, stack, role, and limitations
- 🌏 Bilingual VI/EN content for local and international reviewers
- ⚡ Static-first Astro pages that stay fast and easy to deploy

## 🧭 Main Sections

| Section | Purpose |
| --- | --- |
| `About` | Career direction, learning style, and MLOps narrative |
| `Resume` | Education, project experience, and skill groups |
| `Portfolio` | Selected personal projects with problem, role, stack, and status |
| `Blog` | Publishable VI/EN notes about MLOps and ML systems |
| `Contact` | Friendly contact entry point for recruiters, engineers, and collaborators |
| `CV` | Embedded and downloadable PDF CV |

## 🛠️ Tech Stack

- **Framework:** Astro
- **Content:** Astro Content Collections with Markdown
- **Styling:** Scoped Astro CSS + shared global tokens
- **Images:** `astro:assets` optimized image pipeline
- **Deployment:** GitHub Actions to GitHub Pages

## 🚀 Local Development

```bash
npm install
npm run dev
```

Build before publishing:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 📦 Deployment

Pushes to `main` deploy automatically via `.github/workflows/deploy.yml`.

GitHub Pages should be configured to use **GitHub Actions** as the source. The site is configured for:

```text
https://dyu20705.github.io
```

## 🌱 Content Principles

- Keep claims grounded in real projects and visible evidence.
- Mark project status honestly: MVP, experimental, in development, maintained, or prototype.
- Update VI and EN text together whenever portfolio content changes.
- Prefer small, reliable improvements over broad redesigns.

## 🧩 Portfolio Mood

Professional, but not stiff. Technical, but still human. A little sparkle is welcome as long as the engineering story stays clear.
